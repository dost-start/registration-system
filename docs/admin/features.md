## Admin Features

### Dashboard
- Stats: total, accepted, rejected, pending, checked-in
- Event info and quick actions

### Registrant Management
- Table with sort/filter/pagination
- View details and remarks
- Update status: pending/accepted/rejected
- Toggle check-in (single or batch)
- Edit registrant info
- Delete registrant

Backed by `src/lib/data.ts` functions.

### Event Registration Toggle
- Open/close registration (writes to `options` table)
